# Labs — runnable code for the AI Systems Engineering Masterclass

Every code block the course teaches from lives here, so it can be run and tested.
Lessons embed regions with `@@include(labs/<path>#<region>)@@` (text between `[START region]` and `[END region]`).

Environment legend: **local** = laptop CPU, Python 3.11+ · **gpu** = NVIDIA GPU · **cluster** = Kubernetes.
Test status for each lab is recorded in `labs/TEST_RESULTS.md` (generated by `labs/run_tests.sh`).
